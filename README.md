# EXCEL-RETAIL-SALES-ANALYSIS
# Retail Sales Analysis Dashboard

## Project Overview
This project analyzes retail sales data using Microsoft Excel to understand sales performance, profitability, customer behavior, and regional trends.

## Project Objectives
- Analyze total sales and profit
- Identify top-performing product categories
- Compare sales performance across regions
- Analyze monthly sales trends
- Identify top customers based on profit
- Create an interactive sales dashboard

## Tools Used
- Microsoft Excel 2016
- PivotTables
- PivotCharts
- Excel Slicers
- Excel Formulas

## Data Cleaning
- Checked duplicate records
- Reviewed missing values
- Corrected date and number formats
- Created Year and Month columns
- Prepared data for analysis

## Analysis
- Sales by Category
- Sales by Region
- Profit by Year
- Monthly Sales Trend
- Top 5 Customers by Profit
- Customer Count by Year

## Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Customer Count KPI
- Order Count KPI
- Interactive Category, Year, and Month slicers
